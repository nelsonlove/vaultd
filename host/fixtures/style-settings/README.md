# Style Settings parity fixture

A small Obsidian vault for the parity capture of the Style Settings plugin (task 1 of `docs/design/web-plugins.md`, section 6). It holds a theme and a snippet that each carry an `@settings` block, the stock Style Settings 1.0.9 release bundle (GPL-3.0, with its licence file), and a saved `data.json`.

It is generated by hand. It is not made from, and holds nothing from, any real vault.

- `vault/.obsidian/themes/Fixture Theme/theme.css`: one `@settings` block (section `fixture-theme`) with one setting of each type.
- `vault/.obsidian/snippets/fixture-snippet.css`: its own block (section `fixture-snippet`, two settings).
- `vault/.obsidian/plugins/obsidian-style-settings/data.json`: saved values for about half the settings, one `@@light` key, one `@@dark` key, one key for a setting the theme no longer has (the plugin prunes it on load) and one key for a section that is not loaded.

To capture, copy `vault/` to a scratch path outside the repository, open that copy in Obsidian, then run `node host/scripts/style-settings-capture.js capture --vault <copy> --out host/fixtures/style-settings/expected`. The script refuses to run against any other vault. The captured files go to `expected/`.
